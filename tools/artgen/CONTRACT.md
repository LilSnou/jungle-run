# CONTRACT.md — компактный контракт ассетов для генератора Jungle Run

Полная спецификация — tools/artgen/SPEC.md (96КБ, НЕ читать целиком!). Этот файл — сжатый контракт.

## Стиль
8-битный пиксель-арт, без anti-aliasing, чёткие силуэты, тёмный контур `#141220` где уместно, 2-3 оттенка на материал, блики/тени, выразительные анимации. Богаче и детальнее текущего арта, но в той же стилистике. Все PNG — RGBA с прозрачностью (кроме неба-градиента, он непрозрачный).

## Тайлы (godot/assets/tiles/tiles_<biome>.png) — полоса 4 ячеек 16×16 (итого 64×16)
Структура ячейки: y0..1 — цвет groundLine, y2..7 — groundTop, y8..15 — groundDirt + крапинка groundShade. Ячейки: 0 — крапинка 7×3 (y=12), 1 — крапинка 4×2 (y=9), 2 — чистая, 3 — чистая.
- jungle: line `#2f6b28`, top `#4e9a3f`, dirt `#6b4a25`, shade `#54381b`
- village: line `#5c381b`, top `#b98a4b`, dirt `#8a5a2e`, shade `#6e4522`
- temple: line `#8a9099`, top `#6a6f78`, dirt `#4a4e56`, shade `#3a3d44`

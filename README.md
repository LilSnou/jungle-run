## 📖 О герое

Безымянный искатель приключений в федоре спасается из джунглей, сбежавших
храмов и деревень воинственных племён. Он **бежит автоматически** — игроку
остаётся только вовремя нажимать две кнопки: **ПРЫЖОК** и **СКОЛЬЖЕНИЕ**.

## 🎮 Управление

| Действие | Телефон (тач-зоны без кнопок на экране) | Клавиатура |
|---|---|---|
| Прыжок (дважды — двойной!) | правая половина экрана | `Space` / `↑` / `W` |
| Скольжение (под лианами, верёвками и летучими мышами) | левая нижняя четверть экрана | `↓` / `S` (удерживать) |
| Пауза | кнопка ⏸ справа сверху | `P` / `Esc` |
| Звук вкл/выкл | кнопка 🔊 справа сверху | `M` |

Экранных кнопок прыжка/скольжения нет — только прозрачные тач-зоны,
поэтому экран не засоряется. Весь интерфейс на русском
(только логотип «JUNGLE RUN» остался английским).

### Механики паркура

- **Прыжок** — с «кайот-таймом» и буфером нажатия, как в хороших платформерах
- **Двойной прыжок** — для высоких статуй и связок препятствий
- **Скольжение** — под низко подвешенными брёвнами и летучими мышами (встать под бревном нельзя — пока не проедет)
- **Stomp** — прыжок на голову врага убивает его и даёт отскок
- **Ямы** — провалиться = потерять сердце и возродиться по ту сторону
- Собирайте **золотые монетки майя** (очки) и **сердечки** (+1 жизнь) —
  они никогда не появляются внутри препятствий

### Препятствия и враги

| Локация | Препятствия | Враги |
|---|---|---|
| 🌿 Джунгли | шипы, ямы, лианы (проскользнуть) | змеи-кобры, летучие мыши, ягуары |
| 🛖 Деревня аборигенов | шипы, ямы, верёвки-ловушки | воины-метатели копий, ягуары, змеи |
| 🏛️ Храм майя | каменные статуи (двойной прыжок!), длинные ямы, шипы, каменные балки | воины, летучие мыши, ягуары |

Враги и препятствия «на уровне» героя — с ними легко свериться глазами.
**Скорость растёт к концу каждой локации и сбрасывается на новой**, а с каждым
кругом петли базовая скорость чуть выше.

## 🔊 Звук

Ни одного аудиофайла: вся музыка и эффекты **синтезируются на лету** через
Web Audio API в стиле чиптюнов NES — квадратные волны (бас и мелодия),
шумовой канал (ударные). У каждого биома свой саундтрек со своим темпом.

## 🕹 Как играть

### Веб-версия

1. Открой **[lilsnou.github.io/jungle-run](https://lilsnou.github.io/jungle-run/)** (GitHub Pages)
   или локально:

```bash
cd web
npx serve .        # или: python -m http.server 8000
```

2. Открой `http://localhost:3000` (или `:8000`) — тапни экран, чтобы стартовать.

### Android-версия

Android-версия — это тот же движок в WebView-обёртке
(`android/app/src/main/assets/game/` — копия `web/`), поэтому версии
гарантированно не расходятся.

**Вариант 1 — GitHub Actions (без установки чего-либо):**
пуш в репозиторий собирает APK автоматически → вкладка **Actions** →
последний билд → артефакт `JungleRun-debug-apk`.

**Вариант 2 — Android Studio:**
открыть папку `android/` → Run ▶ (нужен Android SDK 35 и JDK 17).

**Вариант 3 — командная строка:**

```bash
cd android
./gradlew assembleDebug
# APK: android/app/build/outputs/apk/debug/app-debug.apk
```

Требования: Android 8.0+ (API 26), экран любой — игра масштабируется
с сохранением пропорций и работает в альбомной ориентации.

## ✨ Крутые фишки

- **Полностью пиксельный арт**: все спрайты (герой, враги, идолы) описаны
  как «карты пикселей» и строятся в офскрин-канвасы при старте
- **Свой растровый шрифт 5×7** — включая кириллицу: интерфейс на русском
- **Процедурные фоны**: параллакс из 6–8 слоёв для каждого биома
  (водопады и лучи света в джунглях, закат и костры в деревне,
  светящиеся маски и луна в храме)
- **Ретро-физика** с современными подгонками (буфер прыжка, кайот-тайм)

## 🧱 Принципы ООП в игре

Игра — демонстрация принципов объектно-ориентированного программирования.
Каждый класс играет свою роль, а иерархия выстроена по классическим правилам:

| Принцип | Где в коде |
|---|---|
| **Абстракция** | `Entity`, `Enemy`, `Obstacle`, `Item`, `Biome` — абстрактные базовые классы с нереализованными методами (`update`/`draw`/`getPattern`) |
| **Инкапсуляция** | Приватные поля `#vy`, `#lives`, `#listeners`, `#ctx`… Наружу — только геттеры (`Player.vy`, `Player.lives`, `AudioManager.muted`) |
| **Наследование** | `Player extends Entity`; `Snake/Jaguar/Bat/Warrior extends Enemy`; `Spikes/Statue/Pit extends Obstacle`; `Vine/RopeTrap/StoneBeam extends LowLog`; `Jungle/Village/Temple extends Biome` |
| **Полиморфизм** | `World` вызывает `update(dt)`/`draw(ctx)` у сущностей, не зная конкретных классов; каждое препятствие само решает, как выглядит его хитбокс; каждый биом сам рисует свой фон и генерирует свою трассу |
| **Паттерн «Одиночка»** | `AudioManager.instance` — единственный звуковой движок на всю игру |
| **Паттерн «Фабрика»** | `EnemyFactory`, `ObstacleFactory`, `ItemFactory` — генератор уровня описывает трассу данными, фабрики создают объекты |
| **Паттерн «Состояние»** | `MenuState` → `PlayState` ⇄ `PauseState`, `PlayState` → `OverState` (`js/game/Game.js`) |
| **Паттерн «Наблюдатель»** | `EventBus`: `Player` кричит `'player:jump'`, а `HUD`, звук и `Game` подписаны и не знают друг о друге |
| **Паттерн «Фасад»** | `Input` скрывает детали клавиатуры/тача за игровыми действиями `jump`/`slide`/`pause` |
| **Композиция** | `World` *владеет* игроком, биомом, сущностями и частицами; `Player` *содержит* логику анимации, физики, жизней |

Структура:

```
web/
├── index.html
├── js/
│   ├── core/        Config, EventBus, Input, AudioManager (Singleton)
│   ├── gfx/         PixelFont (растровый шрифт), SpriteStore (Factory)
│   ├── entities/    Entity → Player, enemies/, obstacles/, items/, projectiles/
│   ├── world/       Biome → Jungle/Village/Temple, Factories, World
│   ├── ui/          HUD, TouchControls, PauseButton
│   ├── game/        Game (State pattern)
│   └── main.js
└── test/smoke.js    headless-тест на Node.js

android/
├── app/src/main/assets/game/   ← копия web/
├── app/src/main/java/.../MainActivity.kt (WebView-обёртка)
└── gradle wrapper — открывай в Android Studio и собирай APK
```

## 🧪 Тесты

Логика игры проверяется без браузера — на мок-канвасе в Node.js:

```bash
node web/test/smoke.js
```

Тест прогоняет 27 сценариев: старт, паркур с ИИ-игроком, смена всех локаций,
стомп, урон, пауза, смерть, экран Game Over, рестарт и рекорд — плюс
рост скорости внутри локации, её сброс на новой локации и проверка того,
что монетки не появляются внутри препятствий.
